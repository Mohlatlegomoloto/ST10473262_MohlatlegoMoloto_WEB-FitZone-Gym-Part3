2. Project Overview

FitZone Gym is a website developed to introduce visitors to the gym, its membership packages, fitness classes and contact information.

The website is aimed at people in Pretoria who are interested in improving their fitness and finding suitable exercise programmes.

I initially started with a Bakery Shop website in Part 1 but experienced some difficulties with the project. I received 36/100 and decided to change my concept to FitZone Gym. In Part 2, I focused on building the website using HTML and CSS, receiving 56/100.

For Part 3, I continued improving the FitZone Gym website by introducing JavaScript, interactive features, forms, SEO improvements and responsive design.

The main goal is to create a professional, attractive and easy-to-use website that works across different devices.

3. Website Objectives

The main objectives of the website are to:

Introduce visitors to FitZone Gym and its services.
Display membership packages and monthly prices.
Provide information about available fitness classes.
Allow visitors to search for fitness classes.
Allow potential customers to submit membership enquiries.
Provide a contact form for customer communication.
Display the gym’s location using Google Maps.
Make the website accessible on computers, tablets and mobile phones.

6. JavaScript Functionality

JavaScript was introduced in Part 3 to make the website more interactive.

The following features were added:

6.1 Responsive Navigation Menu

A menu button allows visitors to open and close the navigation menu on smaller screens. This makes the website easier to use on mobile devices.

6.2 Image Gallery Lightbox

Visitors can click on gallery images to view them in a larger size. The image can be closed using the close button, clicking outside the image or pressing the Escape key.

6.3 Fitness Class Search

A search feature allows visitors to find classes such as Strength Training, Cardio, Yoga and HIIT. The results update according to the words entered. A message is displayed when no matching classes are found.

6.4 Membership Enquiry Form

The membership enquiry form allows visitors to provide their details and select a preferred membership package.

The available packages are:

Basic – R299 per month.
Standard – R499 per month.
Premium – R799 per month.
JavaScript displays a response based on the selected membership.

6.5 Contact Form

The contact form collects the visitor’s name, email address, phone number and message.

JavaScript checks that the required information has been provided and prepares an email using the visitor’s email application.

The website does not currently store enquiries or send emails automatically. This would require a backend or an email service.

7. Responsive Website Design

The website was designed to work on desktop computers, tablets and mobile phones.

CSS media queries were used to adjust the layout according to different screen sizes.

I checked important areas such as the navigation menu, images, membership cards, buttons, forms and footer.

The mobile navigation also uses a menu button to make it easier for visitors to move between pages.
